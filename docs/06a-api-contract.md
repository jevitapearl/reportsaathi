# API Contract Specification: ReportSaathi
*References: `docs/05-prd.md`, `docs/06-architecture.md`, `docs/06b-safety-rules.md`*

---

## 1. Specification Overview

- **Protocol:** HTTPS (TLS 1.3 mandatory in production)
- **Base URL:** `/api/v1`
- **Data Format:** `application/json` (except image upload which uses `multipart/form-data`)
- **Character Encoding:** UTF-8
- **Authentication:** Ephemeral session headers (`X-Session-ID` and `X-Session-Token`)

---

## 2. Global Headers & Error Schemas

### Request Headers
| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `X-Session-ID` | String (UUIDv4) | Yes (except `/sessions`) | Ephemeral session identifier |
| `X-Session-Token` | String (Hex 64) | Yes (except `/sessions`) | HMAC-SHA256 signature generated by server |
| `Accept-Language` | String | No | Client preferred language (`hi` or `en`) |

### Standard Error Schema (`ErrorResponse`)
```json
{
  "error_code": "STRING_ENUM",
  "message": "Human readable message in requested language",
  "details": {},
  "timestamp": "2026-11-13T12:00:00Z"
}
```

### Common Error Codes
- `INVALID_SESSION`: Session ID not found or HMAC token signature mismatch (HTTP 401).
- `SESSION_EXPIRED`: Session exceeded 24-hour TTL (HTTP 401).
- `PAYLOAD_TOO_LARGE`: Image upload exceeds 10MB limit (HTTP 413).
- `UNSUPPORTED_MEDIA_TYPE`: Non-image file format (HTTP 415).
- `OCR_EXTRACTION_FAILED`: Image too blurry, skewed, or corrupt (HTTP 422).
- `FORMULARY_NOT_FOUND`: Medication not present in top-100 whitelist (HTTP 404).
- `RATE_LIMIT_EXCEEDED`: Too many requests from client IP (HTTP 429).
- `INTERNAL_ERROR`: Unexpected server error (HTTP 500).

## 3. Endpoints

### 3.1 Initialize Ephemeral Session
- **Route:** `POST /api/v1/sessions`
- **Purpose:** Creates a 24-hour ephemeral session without requiring user authentication.

#### Request Payload
```json
{
  "language_code": "hi"
}
```
*Validation:* `language_code` must be either `"hi"` or `"en"`.

#### Response (201 Created)
```json
{
  "session_id": "c8b417e2-411a-4d2a-89aa-0e2417d4efb1",
  "session_token": "a8f3b9c7e2d14890a5b6c7d8e9f01234567890abcdef1234567890abcdef1234",
  "language_code": "hi",
  "expires_at": "2026-11-14T12:00:00Z"
}
```

### 3.2 Upload Prescription Image for OCR Extraction
- **Route:** `POST /api/v1/prescriptions/upload`
- **Purpose:** Accepts a prescription photo, runs server-side image preprocessing and OCR, and fuzzy-matches against the formulary whitelist.

#### Request Headers
- `X-Session-ID`: UUIDv4
- `X-Session-Token`: HMAC string
- `Content-Type`: `multipart/form-data`

#### Form Fields
- `file`: Binary image (JPEG, PNG, WebP; max 10MB).

#### Response (200 OK)
```json
{
  "upload_id": "9d1b6cf0-781e-450f-96a9-83561a0d7831",
  "status": "completed",
  "ocr_text_preview": "Rx Geminor M2 1 tab od morning, Telvas 40 1 tab od",
  "matched_medications": [
    {
      "formulary_id": "FORM_MET_GLIM_01",
      "detected_brand": "Geminor M2",
      "generic_name": "Glimepiride (2mg) + Metformin (500mg)",
      "indication": "ब्लड शुगर / डायबिटीज नियंत्रण",
      "default_slot": "morning_with_food",
      "confidence": 0.94
    },
    {
      "formulary_id": "FORM_TELVAS_40",
      "detected_brand": "Telvas 40",
      "generic_name": "Telmisartan (40mg)",
      "indication": "ब्लड प्रेशर (BP) नियंत्रण",

}
```

#### Error Response (422 Unprocessable Entity - Blurry Image)
```json
{
  "error_code": "OCR_EXTRACTION_FAILED",
  "message": "फोटो साफ़ नहीं दिख रही है। कृपया अच्छी रोशनी में दोबारा फोटो खींचें।",
  "details": { "sharpness_score": 14.2, "min_required": 45.0 }
}
```

### 3.3 Formulary Auto-Complete Search
- **Route:** `GET /api/v1/formulary/search`
- **Purpose:** Instant auto-complete for manual entry fallback.

#### Query Parameters
- `q`: Search string (min length 2 characters).
- `lang`: `hi` or `en` (default `hi`).

#### Response (200 OK)

### 3.5 Stream Synthesized Audio
- **Route:** `GET /api/v1/audio/{schedule_id}.opus`
- **Purpose:** Streams 32kbps mono Opus audio directly to HTML5 audio element.
- **Headers Returned:**
  - `Content-Type: audio/ogg; codecs=opus`
  - `Accept-Ranges: bytes`
  - `Cache-Control: public, max-age=86400`

---

### 3.6 Public Read-Only Web View (WhatsApp Landing Page)
- **Route:** `GET /s/{share_token}`
- **Purpose:** Zero-login mobile page viewed by the parent after clicking a WhatsApp link.
- **Response (200 OK):** Semantic HTML rendering the visual schedule and embedded audio player.
